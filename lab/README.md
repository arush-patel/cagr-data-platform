# Lab

**In short:** where research happens. Notebooks, feature ideas and label drafts live here, and
they use the `cagr` toolkit for everything shared.

| Folder | Holds |
|---|---|
| `features/` | Features shared by everyone, as `@fs.feature` functions. `price.py` has the first six |
| `labels/` | Label drafts, as `@fs.label` functions |
| `tests/` | Checks every shared feature for look-ahead. Runs in CI |

A feature you want others to use goes in `features/` with a test run. Try it first with
`cagr.data.preview` on a few symbols.
